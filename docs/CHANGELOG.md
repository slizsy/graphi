# Changelog

## 1.3.0

- New: Chrome and Chromium support (Edge, Brave and others), built from the same code as the Firefox version.
- Slate, Lexical, Draft.js, Monaco and Google Docs all work on Chromium, which handles extension edits differently from Firefox.
- Project reorganised into `src/`, `platforms/`, `scripts/`, `tests/` and `docs/`.

## 1.2.0

- New: scheduled breaks. Stop for a minute or a few every 15 to 60 minutes of typing.
- New: reports now break the session down by paragraph and by minute, and list the settings used.
- New: print or save a report as a PDF.

## 1.1.0

- New: "Finish in" pacing. Pick a time instead of a speed.
- New: session reports with charts and a full replay.
- New: works in private windows once you allow it.
- Renamed to Graphi.

## 1.0.0

- First release for Firefox.
